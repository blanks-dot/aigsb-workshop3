Left alone, AI drifts to the average

Hintze et al., 2025

Why? Each round drops what's unusual and fills the gap with what's most common. 100 rounds = visual elevator music

Key takeaway: Without precision, AI goes back to the average. - Researchers played telephone with AI. One model draws a picture from a sentence, another describes the picture, and they repeat that 100 times. - 100 different starting sentences, 700 runs, and they ended up as just 12 kinds of picture: stormy lighthouses, cities at night, palace interiors. - Each round drops what's unusual and fills the gap with the most common version. They called it visual elevator music. (Hintze et al., Patterns, 2025) - Your bio and your site drift the same way unless you steer.

AI only knows what's in front of it

Under the hood: three terms that explain why skills work.

1 CONTEXT WINDOW

Its working memory

Everything in the chat, up to a limit. Too crowded, it drifts. Start fresh.

2 FEW-SHOT PROMPTING

Show, don’t tell

3 real samples beat 30 rules. Works for words and visuals.

3 PROGRESSIVE DISCLOSURE

ryc-brand/

SKILL.md

name + description always

the rest on match

assets/colors.css if needed

It reads the label first

Only the name + description load until your ask matches.

so the description is the most important line you'll write

Key takeaway: AI only knows what's in front of it. Skills put the right stuff in front of it at the right time. - Context window: Claude's working memory. Everything in the chat counts. When it gets crowded, older stuff gets fuzzy and it drifts, so start a fresh chat. Your skills come with you. - Few-shot prompting: show, don't tell. Three real samples teach your style better than 30 rules. Same for design: show it two sites you love. - Progressive disclosure: Claude always sees every skill's name and description, opens the full file only when your ask matches, and pulls bundled files like a color sheet only if it needs them. - So the description is the most important line you'll write. Write it like a trigger: "use whenever I write as me."
