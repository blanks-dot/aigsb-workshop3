GitHub keeps every version of your site, like version history in Google Docs. Each drop on Vercel makes a new project, so GitHub is also how you keep one link as you change things

  1. Free account at github.com/signup
  2. + › New repository. Name it yourname-site, Public. Create
  3. Add file › Upload files. Drag in index.html. Commit changes
  4. In Vercel, Add New › Project › import that repo › Deploy. Every upload after that goes live on its own

Every screen is in the long version

Level up: no vercel in your link. GitHub can host it too. In your repo, Settings › Pages › Deploy from a branch › main › Save. In a minute or two it's live at yourname.github.io/yourname-site

Swap yourname-site.vercel.app for yourname.com

  1. Buy the name at any domain seller, or inside Vercel
  2. In Vercel, open your project › Settings › Domains › add yourname.com
  3. Vercel shows the DNS records to add at your seller. Add them, then wait. Minutes, sometimes an hour

Stuck on DNS? Screenshot both pages and ask Claude which record goes where
