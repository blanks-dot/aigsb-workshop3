Step 6, every screen

Right now your site is a file on your laptop, like a letter in a drawer. Hosting mails it to an address anyone can visit. You need one file and a free Vercel account. Stuck? Ask Claude to walk you through it. Screenshot the page and ask what to click next

With Vercel Drop

  1. Get one file. In the chat where you built your site, ask Claude: Give me my whole site as one file called index.html. Download it. index.html is the name websites use for the front door.
  2. Open Vercel Drop. Go to vercel.com/drop and sign up free. GitHub or email both work. Pick the Hobby plan.
  3. Drag & deploy. Drag index.html onto the page. Name the project yourname-site. Hit Deploy. Under a minute.
  4. Copy your link and paste it into step 5 on the workshop site. With the gallery box ticked, it shows in the class gallery on its own. Open it on your phone too.

Check your link opens on your phone with your name on it

A link you can text to someone

Changed something?

Each drop makes a new Vercel project with a new link. Drop the new index.html, then paste the new link into step 5. Want the same link every time? Use GitHub, below

Optional: with GitHub

GitHub keeps every version of your site, like version history in Google Docs, and Vercel redeploys every time you upload. Same link forever

  1. Create a GitHub account. Any email works. Pick a username you'd put on a resume. It's in the link.
    github.com/signup
  2. New repository. Top right, + › New repository. Name it yourname-site. Public. Nothing else ticked. Create repository.
  3. Upload index.html. On the empty repo page, Add file › Upload files. Drag index.html in. Commit changes. It must sit at the top level, not in a folder.
  4. Connect Vercel to GitHub. Signed up with GitHub? Skip this. Signed up with email? In Vercel, Add New › Project, then under Import Git Repository pick GitHub and allow it.
  5. Add New › Project › Import › Deploy. Find yourname-site, click Import. Leave the settings alone. Deploy.
  6. Copy your live link and paste it into step 5. To change the site later, upload the new index.html in GitHub. Vercel redeploys on its own in about a minute.

Stuck?

vercel.com/drop asks me to sign in

That's normal. Sign up free with GitHub or email, pick Hobby, then go back to vercel.com/drop

I dropped the file and see a blank page or a 404

The file must be named exactly index.html. Rename it and drop it again. With GitHub, it also has to sit at the top of the repo, not in a folder

Where's my link?

Vercel shows it once the deploy finishes. Lost it? Open the project in Vercel. It's under Domains

Vercel asks for a payment method

Wrong plan. Go back and choose Hobby. Free for personal sites

My photo doesn't show up

The page points to a file Vercel doesn't have. Ask Claude to put the photo inside the HTML, then drop the file again

With GitHub: can't see my GitHub in Vercel

Connect it after the fact: Settings › Git, or Add New › Project › Import Git Repository › Add GitHub Account. Signing up with Continue with GitHub links them from the start

With GitHub: Vercel can't see the repo

In the import list, the GitHub App Permissions link. Give it the repo, or all your repos. Reload

With GitHub: I changed something and the site didn't update

Upload the file again in GitHub, same name. More than two minutes? Open the Vercel project, Deployments. A red one tells you why

Want a real domain later? Buy one anywhere, then in Vercel, Settings › Domains. Back to the workshop
