Step 6, every screen.

GitHub holds the file. Vercel serves it. You need your index.html and two free accounts. Stuck on either? Ask Claude to walk you through it. It can do most of it.

  1. Create a GitHub account. Any email works. Pick a username you'd put on a resume. It's in the link.
    github.com/signup
  2. New repository. Top right, + › New repository. Name it yourname-site. Public. Nothing else ticked. Create repository.
  3. Upload index.html. On the empty repo page, Add file › Upload files. Drag index.html in. Commit changes. The name must be exactly index.html, at the top level, not in a folder.
  4. Vercel, sign up with GitHub. Continue with GitHub and allow it. Hobby plan. Free.
    vercel.com/signup
  5. Add New › Project › Import › Deploy. Find yourname-site, click Import. Leave the settings alone. Deploy. Under a minute.
  6. Copy your live link. It looks like yourname-site.vercel.app. Open it on your phone too.
  7. Paste it into step 6 on the workshop site. With the gallery box ticked, it shows in the class gallery on its own.

Check your link opens on your phone with your name on it.

Done looks like

A link you can text to someone. Every later change is the same move, upload the file again.

Changed something?

Back in GitHub, Add file › Upload files. Drop the new index.html on the old one. Commit changes. Vercel redeploys on its own. About a minute.

Stuck?

Vercel can't see the repo

In the import list, the GitHub App Permissions link. Give it the repo, or all your repos. Reload.

Vercel can't see my GitHub at all

Connect it after the fact: Settings › Git, or Add New › Project › Import Git Repository › Add GitHub Account. Signing up with Continue with GitHub links them from the start.

The page is blank

The file must be index.html at the root of the repo, not in a folder. Rename or move it, commit, wait a minute.

I changed something and the site didn't update

Upload the file again in GitHub, same name. More than two minutes? Open the Vercel project, Deployments. A red one tells you why.

Vercel asks for a payment method

Wrong plan. Go back and choose Hobby. Free for personal sites.

My photo doesn't show up

The page points to a file that isn't in the repo. Upload the photo next to index.html with the exact name, or ask Claude to embed it in the HTML.

Want a real domain later? Buy one anywhere, then in Vercel, Settings › Domains. Back to the workshop.
